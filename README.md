## 📌 Descripción del Ejercicio (Ejercicio 13: Agenda Telefónica Ordenada)
Un programa fabricado para ordenar un listado de llamadas con sus nombres y números respectivos, en un antes y después de cada llamada marcada.

El sistema implementa dos metodologías de ordenamiento de objetos *Contacto* (nombre, teléfono y correo electrónico)[cite: 47]:
1. **Ordenamiento Manual:** Algoritmo programado paso a paso para ordenar alfabéticamente por nombre y, en caso de nombres iguales, por número de teléfono[cite: 47].
2. **Ordenamiento Nativo:** Uso de herramientas de la API de Java (`Comparator` con criterios múltiples y `Arrays.sort()`) para comparar y validar ambas soluciones[cite: 47].
